# Changelog

All notable changes to AquaGuard Portal are documented here.

## [1.2.0] - 2026-06-08

### Added
- Initial repository structure and portal scaffold
- NZ regulatory compliance framework (NES-F, NES-MA, Freshwater Farm Plans)
- Multi-modal sensor pipeline (pH, DO, temperature, turbidity via MQTT)
- Gemma 4 multimodal inference via Ollama (gemma4:e4b)
- LangGraph orchestration layer
- Compliance export module (JSON/CSV)
- Systemd service unit (aquaguard.service)
- HARDWARE_SETUP.md with NZ-specific sensor and enclosure guidance
- COMPLIANCE.md with NES-F 2020 and NES-MA 2026 regulatory mapping
